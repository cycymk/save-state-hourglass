# 魔法能量瓶（暫名 StarJar）— 完整開發計畫與內容規劃

> 版本：v0.1 計畫稿｜日期：2026-10-26
> 一句話定位：**讓孩子用「完成好習慣」換「3C 時間」，並由 App 當公正的裁判，家長不再當警察。**

---

## 1. 產品目標

| 階段 | 目標 | 成功指標 |
|---|---|---|
| 短期（0–3 個月） | 自家孩子養成時間管理習慣 | 連續 4 週每天有紀錄；每日 3C 時間落在約定內；「討價還價」次數明顯下降（家長主觀記錄） |
| 中期（3–9 個月） | 做成真正的 iPad App，能自動鎖 / 解鎖其他 App | TestFlight 給 5–10 個親友家庭試用，週留存 ≥ 60% |
| 長期（9 個月+） | 上架 App Store / Google Play，多語系 | 上架、正評 ≥ 4.5、付費家庭可支撐維運 |

## 2. 核心循環（Core Loop）

```
 完成任務 ──► 獲得「星露」能量 ──► 注滿魔法瓶（100 星露 = 1 瓶）
    ▲                                         │
    │                                         ▼
 準時下線獎勵 ◄── 使用遊戲時間 ◄── 兌換「遊戲券」（1 瓶 = 30 分鐘，可調）
```

- **能量單位：星露**（Star Dew）。數字小、好算：一個任務 10–40 星露。
- **魔法瓶**：視覺上液體逐漸上升、冒泡、滿瓶時有封瓶動畫，收進「瓶架」。
- **遊戲券**：兌換後開始倒數，結束前 5 分鐘、1 分鐘提醒，結束時要按「我準時結束了」。

## 3. 任務系統（AA 任務）

### 3.1 任務類型

| 類型 | 例子 | 驗證方式 | 預設星露 |
|---|---|---|---|
| 專注任務 | 寫作業 25 分、閱讀 20 分 | **App 自動驗證**：番茄鐘全螢幕計時 | 25 / 次 |
| 練習任務 | 鋼琴、小提琴 30 分 | **App 自動驗證**：麥克風偵測聲音才倒數 | 30 / 次 |
| 益智任務 | 心算挑戰、數字華容道 | **App 自動驗證**：答對才給 | 每日上限 20 |
| 生活任務 | 整理書包、刷牙、洗碗 | 自主回報（誠信制）或拍照 | 5–10 |
| 作業任務 | 數學習作 p.12–15 | 拍照 → 家長一鍵核准 | 20–40 |
| 目標任務（時效性） | 段考前完成 5 份作業；比賽前每天練 1 小時 | 由子任務累積，進度條 + 倒數日 | 完成額外大獎 |

### 3.2 三層驗證（口說無憑的解法）

1. **L1 自動驗證**（最常用、零爭議）：計時、聲音、益智題目，App 直接發能量。**把大部分頻繁核准交給 App。**
2. **L2 證據 + 家長核准**：拍照或寫一句心得 → 進入「待核准」→ 家長可以**一次批次核准**（每天睡前 30 秒處理完）。超過 24 小時未處理自動核准（避免家長忘記讓孩子吃虧）。
3. **L3 誠信回報**：小任務孩子自己按完成，能量較低；家長隨機抽查。**誠信值**長期良好 → 解鎖更多可自主回報的任務。

## 4. 防沉迷機制設計（核心賣點）

| # | 機制 | 說明 | 為什麼有效 |
|---|---|---|---|
| 1 | **每日兌換上限** | 平日 60 分、假日 120 分（家長設定） | 能量再多也不會一天玩爆 |
| 2 | **瓶架容量上限** | 最多存 4 瓶，滿了會提示「先用掉或升級成成就」 | 避免囤積後一次狂玩 |
| 3 | **宵禁時段** | 21:00 後不能兌換、遊戲券到 21:30 強制結束 | 保護睡眠 |
| 4 | **必做任務優先** | 今天標記「必做」的任務沒完成 → 兌換鈕鎖住 | 先苦後甘的順序感 |
| 5 | **單次時長上限 + 休息冷卻** | 一張券最多 30 分；兩張券之間至少休息 15 分（提示看遠方、喝水、20-20-20 護眼） | 打斷「再一局」的連續性 |
| 6 | **益智遊戲能量上限** | 小遊戲每日最多 20 星露 | 防止刷小遊戲換時間 |
| 7 | **重複任務遞減** | 同一任務一天第 3 次起能量減半 | 鼓勵多元 |
| 8 | **準時下線獎勵** | 遊戲券結束 1 分鐘內按「準時結束」→ +5 星露、連續 7 天得徽章 | 獎勵**自我停止**，這是最想養成的能力 |
| 9 | **非 3C 獎勵選項** | 瓶子也能換「和爸媽打球」「選晚餐」 | 讓 3C 不是唯一的快樂 |
| 10 | **週報透明** | 每週一張圖：學習時間 vs 3C 時間 | 孩子自己看見比例，家長不用碎念 |

## 5. 避免賴皮與討價還價

- **家庭契約**：首次設定時，親子一起選規則、一起按「簽名」。規則畫面隨時可看。
- **規則只在「家庭會議日」能改**（預設週日）。平日家長也不能臨時改，雙方都受約束 → 孩子信任系統、家長不被盧。
- **申訴額度**：每週 1 次「申訴」機會，寫理由給家長，用完就沒了。
- **App 當裁判**：時間到、能量不足、宵禁 —— 由 App 說「不行」，不是爸媽。
- **所有紀錄不可刪除**，只能由家長加註更正（留痕）。

## 6. 樂器練習 / 專注模式

- 開始 → 進入全螢幕 → 顯示大計時器與魔法陣動畫。
- **聲音偵測**：麥克風音量超過門檻才倒數；安靜超過 10 秒自動暫停並提示「魔法陣暫停了，繼續演奏吧！」。門檻可校準（先安靜 3 秒量環境音）。
- 中途離開 / 切到別的 App → 本次作廢或只給比例能量。
- **iPad 鎖定方式**：
  - 網頁版（v0.x）：使用 iPad 內建 **「引導使用模式（Guided Access）」**，家長設定密碼，三擊側邊鍵啟用 → 孩子無法離開 App。App 內會教學。
  - 原生版（v2）：使用 Apple **Screen Time API（FamilyControls / ManagedSettings）** 自動遮蔽其他 App，完成後自動解除。

## 7. 行事曆與時效性任務

- 週曆檢視：每天的任務、截止日、考試 / 比賽標記。
- **目標任務**：例「11/20 段考」→ 底下掛「數學作業 ×3、國文作業 ×2」，顯示倒數天數與進度條；越接近截止日，App 主動提醒。
- **每日型目標**：例「音樂比賽前每天練 60 分」→ 連續天數火焰 🔥。
- 家長、孩子都可以新增任務；孩子新增的任務需家長確認能量值。
- 後期：匯入 / 匯出 .ics（Google / iCloud 行事曆）、學校月曆一鍵帶入。

## 8. 內建益智小遊戲（休息空檔用）

1. **閃電心算**（60 秒，依年級調難度）← v0.1

## 9. 介面與視覺（台灣中小學生喜好）

### 9.1 觀察重點
- 兒福聯盟 2025 調查：國小五六年級約 8 成、國中約 7.7 成休閒會玩遊戲；網路影片觀看比例相近，國小生偏好抖音、國中生偏好 IG。→ **孩子熟悉短影音節奏與遊戲化回饋，介面需要即時、有動感的回饋。**
- 台灣熱門角色：吉伊卡哇（療癒系）、三麗鷗（布丁狗、大耳狗）、寶可夢、巧虎（低年級）。國中生則偏向動漫、Minecraft / Roblox 這類可自訂、可收集的風格。
- 結論：**國小 = 圓潤可愛、療癒、收集養成；國中 = 不幼稚、可自訂、成就與等級感、暗色模式。**

> 注意：不能使用上述角色（版權），只取「風格」。我們設計原創吉祥物 **「露米 Lumi」**（瓶子裡的小星靈），會隨能量多寡改變表情。

### 9.2 兩套主題
| | 童話魔法（國小） | 星空煉金（國中） |
|---|---|---|
| 色調 | 粉紫、薄荷、奶油黃 | 深藍夜空、霓虹青、金色 |
| 字體 | 大字、圓體 | 一般字級、較俐落 |
| 互動 | 彈跳、星星爆開、露米說話 | 粒子特效、等級、稱號 |
| 文字 | 注音友善、短句 | 簡潔 |

### 9.3 設計原則
- 單手、大按鈕（≥ 56px），iPad 直橫皆可。
- 主畫面只放 3 件事：**魔法瓶、今日任務、兌換按鈕**。
- 回饋 < 0.3 秒：加能量時液體上升 + 音效。
- 不用紅色懲罰感語言，用「魔法陣暫停了」取代「你失敗了」。

## 11. 技術路線

| 階段 | 技術 | 為什麼 | 實際「解鎖 App」方式 |
|---|---|---|---|
| **A. 網頁版 PWA**（v0.1–v0.6） | HTML/JS 單檔 + localStorage，GitHub Pages 託管（HTTPS 才能用麥克風） | 你用 Windows 也能開發；iPad 用 Safari「加入主畫面」即可測試；改版即時 | 遊戲券倒數 + 家長用 iPad「螢幕使用時間」手動設定；專注時用「引導使用模式」鎖定 |
| **B. 雲端同步**（v0.7–v0.9） | Supabase 或 Firebase | 孩子 iPad + 家長手機各自登入，家長在手機核准 | 同上 |
| **C. 原生 iOS**（v1.x） | SwiftUI + FamilyControls / ManagedSettings / DeviceActivity | **只有原生 App 能自動遮蔽 / 解鎖其他 App** | 兌換 → 自動解除遮蔽 N 分鐘 → 時間到自動遮蔽 |
| **D. Android / 全球** | Kotlin（UsageStats + 無障礙服務）或 Flutter | 擴大市場 | 同概念 |

### 原生 iOS 的門檻（要提早準備）
1. **Mac**：Xcode 只能在 macOS 跑。選項：買 Mac mini，或用雲端 Mac / GitHub Actions macOS runner 建置。
2. **Apple Developer Program**：每年 US$99，才能用 TestFlight 裝到 iPad。
3. **Family Controls 發布權限**：需向 Apple 另外申請 `com.apple.developer.family-controls`，審核是人工、可能等數週 → **建議 v0.5 時就送申請**。
4. 被遮蔽的 App 仍可點開，只是蓋上遮罩（Shield）；只能在實機測試，模擬器不支援。

## 14. 隱私與安全（上架前必備）

- 兒童 App 需符合 Apple 兒童類別規範、台灣個資法；海外需符合 COPPA（美）、GDPR-K（歐）。
- 不放廣告、不收集不必要資料；麥克風只在本機判斷音量，**不錄音、不上傳**。
- 家長 PIN 與家長區要有「家長閘門」（如簡單算術題或 PIN）。

## 16. 風險

| 風險 | 對策 |
|---|---|
| 孩子覺得無聊、新鮮感消退 | 每週更新小遊戲 / 徽章；季節活動 |
| 孩子找漏洞（例如放音樂騙聲音偵測） | v0.3 加入「聲音變化度」判斷；家長抽查；誠信值 |
| Apple Family Controls 申請被拖延 | 提早申請；網頁版先撐住 |
| 家長自己破壞規則 | 規則只在家庭會議日可改，家長也受約束 |
